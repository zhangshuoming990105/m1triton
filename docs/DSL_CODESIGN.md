# M1Triton Compiler-DSL Co-Design (`tlx`)

M1Triton compiles both standard Triton kernels (`import m1triton.language as tl`, `@m1triton.jit`, `@m1triton.autotune`) and hardware-specialized Co-design extensions (`import m1triton.tlx as tlx`) through the same pure C++20 SSA + Fusion IR and Metal backend. Every `tlx.*` primitive lowers to a verified SSA IR attribute or op handled by general C++ passes.

## Design Invariants

- **Strict Alignment & PSO Threadgroup Safety**: `EpilogueFusionPass` and `MetalCodegen` require proven 16-byte pointer divisibility before emitting aligned `float4*` accesses (falling back to `packed_float4` or scalar paths otherwise). `MetalRuntime::launch_kernel` validates `tg_threads <= [pso maxTotalThreadsPerThreadgroup]` before every dispatch so register-spilling schedules fail loudly rather than silently dropping execution.
- **64-Bit Tensor Indexing**: Multi-GB tensors compute element addresses in 64-bit `long` (`tl.int64`), using uniform 32-bit fast-paths only where mathematically identical.
- **Cross-Queue Synchronization Discipline**: M1Triton dispatches onto its own `MTLCommandQueue`; multi-stage M1Triton pipelines execute inside concurrent `command_batch()` with automatic RAW/WAW/WAR buffer barriers or static `MetalGraph` Compute ICBs, while kernels returning directly to PyTorch MPS wait explicitly before handing buffers back to MPS.
